# User Guide

## Connect a Device
1. Sign in.
2. Add a device from the Home screen.
3. Enable remote access in device settings.

## Start a Session
- Click Connect on an online device.
- Accept or reject incoming sessions.

## Send a File
- Use the Send File section in the center column.
- Select target device, session, and file.
- Click Start Transfer.

## View Telemetry
- Telemetry appears in the right column when available.

## Troubleshooting
- If a device is offline, verify remote access is enabled.
- If a session fails, check network connectivity and reconnect.
- Session expiry requires re-authentication.
